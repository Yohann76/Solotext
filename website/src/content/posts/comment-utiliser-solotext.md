# Comment utiliser SoloText : Guide complet

Ce guide vous accompagne pas à pas pour tirer le meilleur parti de SoloText et analyser efficacement vos textes.

## Premiers pas

### 1. Créer un compte

Pour commencer, créez votre compte SoloText. L'inscription est gratuite et ne prend que quelques minutes.

### 2. Accéder à l'application

Une fois connecté, vous accédez à votre tableau de bord où vous pouvez :
- Créer une nouvelle analyse
- Consulter vos analyses précédentes
- Exporter vos rapports

## Analyser un texte

### Étape 1 : Saisir votre texte

Dans l'interface d'analyse, collez ou saisissez le texte que vous souhaitez vérifier. Vous pouvez analyser des textes de différentes longueurs.

### Étape 2 : Lancer l'analyse

Cliquez sur le bouton "Analyser" pour lancer la vérification. SoloText va :
- Découper votre texte en phrases
- Rechercher chaque phrase sur internet
- Identifier les duplications potentielles
- Compiler les résultats

### Étape 3 : Consulter les résultats

Les résultats s'affichent avec :
- **Statistiques globales** : Nombre de phrases analysées, taux de duplication
- **Phrases dupliquées** : Liste des phrases détectées avec leurs sources
- **Sources identifiées** : Liens vers les pages web où les duplications ont été trouvées

## Exporter vos analyses

Vous pouvez exporter vos analyses au format PDF pour :
- Les partager avec vos collaborateurs
- Les archiver
- Les inclure dans vos rapports

## Conseils d'utilisation

- **Analysez régulièrement** : Vérifiez vos textes avant publication
- **Consultez l'historique** : Comparez vos analyses pour suivre l'évolution
- **Utilisez les sources** : Vérifiez les sources identifiées pour comprendre les duplications
